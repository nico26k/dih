# Upload checklist

- [ ] Streamer allows clipping (checked `trackers/streamers.csv`)
- [ ] Hook in the first second — no dead air at the start
- [ ] Captions burned in and readable on a phone
- [ ] Streamer credited on screen **and** in the description, with a link
- [ ] Copyrighted background music muted/replaced
- [ ] Title under ~60 characters, streamer name included
- [ ] Thumbnail set (long-form) / cover frame picked (Shorts)
- [ ] Shorts: 9:16, under 60s, `#shorts` in description
- [ ] Added to the right playlist (by streamer)
- [ ] Logged in `trackers/upload-log.csv`
